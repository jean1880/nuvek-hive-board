## hive-board 1.0.0

The first public release of hive-board: the board server, the `hive-mcp` MCP server and the
`hive-gardener` worker, in one repository.

### Highlights

- Board, findings ledger, lifecycle with retention, outcome-based scoring, full-text search and
  the job queue, with the web UI.
- `hive-mcp` and `hive-gardener` ship as static x86_64 Linux binaries; the board ships as a
  container image.

### Secure by default

- The server binds `127.0.0.1` unless `BIND` says otherwise (the container image sets `0.0.0.0`).
- Reads need the bearer token unless `HIVE_AUTH_READS` is explicitly `0`, `false`, `no` or `off`.
  The web UI and `hive-mcp` send the token with every request.
- `HIVE_JOB_OWNS_ROOTS` is empty by default, and empty refuses every job `owns` entry.
- `hive-mcp` and `hive-gardener` load their secret surfaces with `nuvek_core::scrub::init()` and
  exit with code 3 when the configuration cannot be read.
- Redaction covers configuration-shaped credentials (URL userinfo, `password=value`, JSON and
  XML secret keys) on every API write, in the SQLite import, in `hive-mcp`'s brief queries
  (before they reach the board or the embedding model) and in the gardener's distillation.
- `hive-mcp` resolves symlinks in job `owns` paths before posting; the server's checks are
  lexical.
- The gardener never deletes graph nodes.
- Every endpoint default is `localhost`; the gardener's incident bridge is skipped unless
  `HIVE_GARDENER_BRIDGE_URL` is set.

### Configuration to set

Set `BIND=0.0.0.0` if the server must listen beyond loopback, `HIVE_AUTH_READS=0` to keep reads
open, and `HIVE_JOB_OWNS_ROOTS` to the directories jobs may claim. Clients that read need the
token, including a Prometheus scrape of `/metrics`.

### Install

The container image is `ghcr.io/jean1880/nuvek-hive-board`. The `hive-mcp` and `hive-gardener`
binaries below are static x86_64 Linux builds: check them against `SHA256SUMS`.

### Dependencies

`sqlx` 0.8.6 (fixes RUSTSEC-2024-0363) and `rusqlite` 0.32 for the `import` feature.
